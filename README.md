# Telecom-analysis-2026
## Analisis de un Data set para el Spritn 7 de TripleTen Data Analyst Bootcamp
## Objetivo del proyecto

El objetivo de este sprint es aplicar los conocimientos adqiridos dentro del modelo OSEMN (Obtain, Scrub, Explore, Model, Nterpret) para ConnetaTel y generar un reporte con los hallazgos encontrados y recomendaciones finales.
Los datasets utilizados fueron los sigientes
- datasets/plans.csv
- datasets/users_latam.csv
- datasets/usage.csv
Las etapas del análisis realizadas fueron una exploracion de los data sets para identificar Nulos y sentinels, se estandarizaron las fechas para el correcto analisis, despues se trabajo en la imputacion de los nulos a traves de una exploracion de Outliers para poder segmentar a los usuarios por dos gurpos principales, Grupos de Edad y Grupos de Uso.
Finalmente se compararon la distribucion por tipo de plan, Básico o Premium en la misma segmentación de edad y uso para analizar si había diferencias significativas
